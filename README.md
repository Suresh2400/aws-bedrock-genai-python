# 🤖 AWS Bedrock Multi-AI Integration Project

This project demonstrates the integration of multiple AI models using **AWS Bedrock**.  
It showcases how different foundation models (like Claude, Llama, Titan, etc.) can be used in a single application for generating intelligent responses.

---

## 📖 Project Overview

This application is built to explore and implement **AWS Bedrock services**, enabling access to multiple AI models through a unified API.

It allows users to:
- Interact with different AI models
- Compare responses from multiple LLMs
- Build scalable AI-powered applications using AWS cloud services

---

## ⚙️ Features

- 🔹 Integration with AWS Bedrock
- 🔹 Multiple AI model support (Claude, Llama, Titan, etc.)
- 🔹 Secure API-based communication
- 🔹 Scalable cloud architecture
- 🔹 Easy model switching in code

---

## 🧠 AI Models Used

- Amazon Titan Text Model
- Anthropic Claude (via AWS Bedrock)
- Meta Llama 2 / Llama 3
- Other supported foundation models


- ## 🛠️ Tech Stack

- Python 🐍
- AWS Bedrock ☁️
- Boto3 (AWS SDK)
- LangChain (AI orchestration framework)
- Streamlit (UI for GenAI app)
- FAISS (Vector database for similarity search)
- PyPDF (PDF document reading)
- AWS CLI (for cloud configuration)
